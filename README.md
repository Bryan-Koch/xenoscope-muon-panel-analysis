# Xenoscope Muon Panel Analysis

This repository contains the Python-based data analysis developed during a two-week undergraduate summer research internship in the Experimental Astroparticle Physics Group at the University of Zurich. The project focused on the commissioning and characterization of the cosmic-muon panel system of Xenoscope, a full-scale vertical demonstrator for the future DARWIN dark matter observatory.

The full research report is available [here](report/summer_research_report.pdf).

## Project overview

The project investigated cosmic-muon signals recorded by the muon panel system of Xenoscope. Two muon panels were studied using different trigger configurations: events triggered by a coincidence between both panels (AND) and events triggered by either panel (OR). Data from a separate third muon panel positioned on top of Xenoscope were analysed independently.

The main objective was to characterize the detector response, distinguish muon-induced signals from background, and identify a suitable offline pulse-amplitude threshold for selecting muon events while suppressing background contributions.

## Analysis

The analysis processes digitized waveforms from three muon-panel channels (`wf0`, `wf1`, and `wf2`) stored in ROOT files. For each event and channel, the waveform baseline is determined from the first 50 samples and pulses are identified as negative-going deviations from this baseline.

For each detected pulse, the analysis extracts:

- pulse amplitude
- integrated signal area
- number of samples below threshold
- integration-window width

The resulting quantities are stored in Parquet files for further analysis. Their distributions and correlations are studied for the AND and OR trigger configurations of Muon Panels 1 and 2, as well as separately for events triggered by Muon Panel 3, positioned on top of Xenoscope.

## Repository structure

The repository contains three Jupyter notebooks corresponding to the analysed datasets:

- `notebooks/1_and_2_muon.ipynb` — analysis of events triggered by a coincidence between Muon Panels 1 and 2 (AND)
- `notebooks/1_or_2_muon.ipynb` — analysis of events triggered by either Muon Panel 1 or Muon Panel 2 (OR)
- `notebooks/3_muon.ipynb` — analysis of events triggered by Muon Panel 3, positioned on top of Xenoscope
- `report/summer_research_report.pdf` — final report of the undergraduate summer research project

Each notebook performs the waveform processing and provides distributions and correlations of the extracted pulse quantities for the corresponding dataset.

## Data

The original Xenoscope ROOT waveform data are not included in this repository. The processed Parquet files generated by the notebooks are also excluded from version control.

To reproduce the analysis with suitable input data, the data paths defined at the beginning of each notebook must be adapted to the local location of the corresponding ROOT files.

## Requirements

The analysis is implemented in Python using the following packages:

- `uproot` — reading ROOT files
- `awkward` — handling and storing event data
- `numpy` — numerical calculations
- `matplotlib` — visualization

The notebooks can be run in a Jupyter environment with these dependencies installed.

## Results

Comparison of the analysed datasets showed a clear separation between the low-amplitude background-dominated population and the higher-amplitude population associated with cosmic-muon signals. Based on the observed transition region, an offline pulse-amplitude threshold of approximately **1000 ± 200 ADC** was proposed for identifying muon events.

This value represents an empirical estimate from the observed distributions rather than the result of a statistical fit.
